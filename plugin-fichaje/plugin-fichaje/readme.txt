=== Plugin Fichaje ===
Requires at least: 5.8
Tested up to: 6.7
Requires PHP: 7.4
License: GPLv2 or later

Sistema de registro de jornada laboral conforme al RDL 8/2019 (Art. 34.9 ET).

== INSTALACIÓN ==
1. Sube el zip desde WordPress Admin -> Plugins -> Añadir nuevo -> Subir plugin
2. Activa el plugin
3. Las tablas de base de datos se crean automáticamente al activar

== USO ==
- Panel de administración: Menú lateral "Fichaje"
- Botón en página: añade el shortcode [fichaje] en cualquier página

== CUMPLIMIENTO LEGAL ==
✅ Hora exacta de entrada y salida
✅ IP del dispositivo (trazabilidad)
✅ Correcciones manuales con motivo obligatorio
✅ Log de auditoría inmutable
✅ Exportación CSV/Excel para inspecciones
✅ Retención 4 años (datos no se borran al desactivar)

== SHORTCODE ==
[fichaje]               — Widget completo
[fichaje show_team="no"] — Solo botón personal
